# Protótipo · São Paulo Languages Academy (nome provisório)

Protótipo navegável de um app de inglês profissional para quem trabalha no Brasil (TI/SAP, bancos, finanças, indústria, escritórios). Interface em pt-BR. Dados de demonstração.

- **v6 (atual):** [v6/](https://junweel.github.io/prototipo-app-ingles/v6/) · ciclo Memória → Uso → Avaliação (Erick, Sophia, Teacher Lili), ciclo do erro, progresso por frase, sotaques (placeholder), modo reunião real (opt-in, sem áudio), praticar com seu material, checkpoint semanal, "Seu progresso real" (dados de exemplo). A raiz redireciona para a v6. Nenhuma tela anterior removida.
- **v5:** [v5/](https://junweel.github.io/prototipo-app-ingles/v5/)
- **v4:** [v4/](https://junweel.github.io/prototipo-app-ingles/v4/) (antes na raiz) · novo visual preto/creme/amarelo/vermelho, padrão do piso paulista, logo opção 2, personagens redesenhados, layout desktop (> 1024 px) com barra lateral. `?view=phone` força a moldura de celular; `?view=desktop` força o desktop.
- **v3 (comparação):** [v3/index.html](https://junweel.github.io/prototipo-app-ingles/v3/index.html)
- Marca: `assets/brand-board.png`, ícones e personagens em `assets/`.

Padrão inspirado no piso paulista criado por Mirthes Bernardes (1966). Personagens ilustrados e fictícios.
